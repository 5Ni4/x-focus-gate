# 解け！ v1.11.0

Xのホームタイムラインへ戻る前に、短い四則演算を1問だけ出すChrome系ブラウザ拡張機能です。

問題の生成と正誤判定はブラウザ内で完結し、外部サーバーへの送信は行いません。

## 更新履歴

- v1.11.0: ゲートをclosed Shadow DOMへ移し、DOMからの削除・非表示を自動修復。ゲート外の入力・クリックも遮断

- v1.10.0: OFF時にXタブを閉じないよう修正

- v1.9.0: ポップアップをコンパクト化し、「Xを開く」をボタン化

## ローカルで試す

1. ChromeまたはChromium系ブラウザで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」を選ぶ
4. この `x-focus-extension` フォルダを選ぶ
5. `https://x.com/home` を開く

拡張機能のアイコンから、集中モードと再出題の間隔を変更できます。

## 現在の仕様

- Xを開いたときに1問出題（ログイン画面などを除く）
- 再出題は1分・3分・5分・10分・15分から選択
- 足し算・引き算・掛け算・割り算からランダムに出題
- Escキーでは解除できず、答えの入力が必要
- 拡張機能のポップアップから停止・再開可能
- Xの各ページで作動（ログイン画面などを除く）
- Chromeウィンドウが非アクティブになると、そのウィンドウ内のXタブをすべて閉じる
- ゲート表示中は、DOM操作による単純な削除・非表示を自動的に修復

この拡張機能はブラウザ内で動作するため、利用者が拡張機能を無効化したり、拡張機能のソースを変更したり、ブラウザ自体を操作したりすることまでは防げません。v1.11.0の対策は、Xページ上のDOMを削除するだけの回避を難しくするためのものです。
